# 🎬 Cinetag Alura Aprimorado

## ✨ Visão Geral

O Cinetag foi desenvolvido na aula de React com js da Alura, foi o meio de aprender sobre componentes, hooks, rotas, listas, arrays, apis e finalmente deploy. O Cinetag mostra uma lista de filmes para o usuario navegar entre eles acessar seus trailers e favoritar criando uma lista pessoal de filmes que interessou e deseja assistir!

O Cinetag é uma plataforma interativa de catálogo de filmes e séries, onde os usuários podem visualizar trailers e gerenciar suas listas de favoritos.
